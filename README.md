# Обчислення норми Фробеніуса з використанням MPI

Цей проєкт демонструє використання MPI для паралельного обчислення норми Фробеніуса квадратної або прямокутної матриці.

## Вимоги

- C++ компілятор (наприклад, `g++`)
- OpenMPI (`mpicxx`, `mpirun`)

## Компіляція

```bash
mpicxx -o frobenius main.cpp
